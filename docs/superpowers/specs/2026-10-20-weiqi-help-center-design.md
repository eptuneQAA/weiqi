# 围棋新手帮助中心设计规格

- 日期：2026-10-20
- 状态：已确认
- 项目路径：`/home/UOS/weiqi`
- 关联功能：帮助菜单、围棋规则说明

## 1. 目标

把现有的一小段“规则说明”弹窗升级为面向零基础用户的图文帮助中心，满足：

1. 小白能从“快速开始”直接学会如何开一局、如何落子、如何结束。
2. 用通俗语言解释气、提子、禁入点、劫、眼、活棋、数子等核心规则。
3. 覆盖人机对战、局域网联机、聊天和常见问题。
4. 每个抽象规则配棋盘示意图，降低理解门槛。
5. 只在“帮助”菜单中打开，不在启动时自动弹窗。
6. 支持键盘 F1 打开，支持上一节/下一节浏览。

明确不做：交互式教程、自动弹窗引导、全文搜索、多语言帮助、外链文档。

## 2. 用户体验

- 主菜单“帮助 -> 新手帮助”打开帮助中心，默认显示“快速开始”；F1 等同。
- 主菜单“帮助 -> 规则说明”打开帮助中心并定位到“棋盘与落子”。
- 帮助窗口左侧为章节列表，右侧为可滚动正文；底部有“上一节 / 下一节 / 关闭”和页码。
- 正文用大字号、短段落、列表和“一句话记住”提示；所有文字为简体中文。
- 示意图用程序自绘棋盘，不使用外部图片资源，安装包无需额外资源文件。
- 帮助内容只读，文字可选中复制；不包含可点击外链。
- 关闭后返回主窗口；不改变对局状态。

## 3. 章节与内容

帮助中心共 11 个章节：

1. **快速开始**：围棋目标、三步开一局、落子方式、如何结束、状态栏提示。
2. **棋盘与落子**：交叉点、黑先白后、轮流一手、坐标、已有棋子处不能落子。
3. **气与提子**：气的定义、角/边/中腹的气数、连接共享气、打吃、提子后的变化。
4. **禁入点与劫**：自杀禁入、禁入点示例、劫的形成、不能立即提回、找劫材。
5. **眼与活棋**：眼、真眼、两只真眼活棋、不要填自己的眼。
6. **胜负与数子**：中国规则面积计分、贴目 7.5、连续停一手、死子标记、确认数子、计分示例。
7. **对局操作**：新对局、停一手、认输、悔棋、确认数子、各种状态提示。
8. **人机对战**：三档难度与思考时间、执黑/执白、悔棋规则、AI 定位。
9. **局域网联机**：主机创建房间、客机加入、手动 IP/自动发现、端口、聊天、断线、同机测试。
10. **常见问题**：点棋盘没反应、已有棋子、禁止自杀、劫争、贴目、数子结果、发现失败、AI 强度、联机限制。
11. **术语表**：气、提子、打吃、长、粘、断、眼、真眼/假眼、劫、劫材、星位、天元、贴目、数子、死子、单官。

每章正文使用 `h3` 小标题、短段落、列表和重点提示；控制在适合快速阅读的长度。

## 4. 示意图

示意图由独立的 `DiagramWidget` 自绘，数据为纯 Python 结构：

```python
{
    "caption": "白棋有 4 口气（绿色空点）",
    "size": 9,
    "stones": [(4, 4, WHITE)],
    "highlights": [(3, 4, "green"), (5, 4, "green"),
                   (4, 3, "green"), (4, 5, "green")],
    "marks": [],
}
```

- 共同字段：`caption`、`size`（默认 9）、`stones`、`highlights`、`marks`。
- `stones`：`(x, y, BLACK/WHITE)`；坐标必须在棋盘内。
- `highlights`：`(x, y, color_name)`；绿色表示气/眼/领地，红色表示危险/禁入，蓝色表示提示点。
- `marks`：`(x, y, text, color_name)`；支持数字“1/2”、字母和“×”；`×` 画成红叉。
- 示意图不显示坐标，保持画面简洁；棋盘、网格、星位、棋子沿用主棋盘配色。
- 每张图下方有居中小字说明，正文解释规则，图辅助理解。

章节配图：

- 快速开始：棋子落在交叉点。
- 气与提子：4 口气、只剩 1 口气、提子后。
- 禁入点与劫：自杀禁入点、劫的形状与“1/2”标记。
- 眼与活棋：一块棋的两只真眼。
- 胜负与数子：黑/白各自围住的领地。

## 5. 组件与文件

```
weiqi/ui/help_content.py    纯 Python 帮助章节与示意图数据
weiqi/ui/help_dialog.py     帮助窗口、正文页面、示意图控件
weiqi/ui/main_window.py     菜单接入与 F1 快捷键
tests/test_help.py          帮助数据完整性测试
```

- `HELP_PAGES`：章节列表，每项含 `id`、`title`、`html`、`diagrams`。
- `HelpDialog`：左侧 `QListWidget`，右侧 `QStackedWidget` + `QScrollArea`。
- `HelpPage`：标题、富文本正文、示意图和说明。
- `DiagramWidget`：固定尺寸方形棋盘，QPainter 自绘。
- 主窗口删除旧的 `_show_rules` 弹窗，改为 `_show_help(page_id)`。

## 6. 菜单接入

帮助菜单：

- “新手帮助”（F1）→ 打开帮助中心，定位“快速开始”。
- “规则说明” → 打开帮助中心，定位“棋盘与落子”。
- “关于” → 保留现有关于对话框。

不自动弹出帮助；不修改对局流程、AI、网络协议或聊天行为。

## 7. 测试与验收

1. `tests/test_help.py`：
   - 章节 ID 唯一，必须包含 11 个约定章节。
   - 每章标题和 HTML 非空，HTML 长度足以覆盖内容。
   - 示意图坐标在棋盘范围内，棋子颜色合法，标记/高亮颜色合法。
   - 关键术语出现在正文中：气、提子、禁入点、劫、两只真眼、贴目 7.5、人机、局域网。
2. 离屏冒烟：`QT_QPA_PLATFORM=offscreen` 创建 `HelpDialog`，逐章切换，确认无异常。
3. 截图检查：帮助窗口排版、示意图、文字换行正常。
4. 打包验证：重新构建 `weiqi_1.0.1_all.deb`，`lintian` 无告警，解包后程序可启动，帮助对话框可打开。

## 8. 边界与异常

- 初始页 ID 不存在时回退到“快速开始”。
- 章节数据为空时显示“帮助内容暂不可用”，不崩溃。
- 示意图数据坐标越界时跳过该点，不抛异常。
- 帮助窗口宽度不足时正文换行、滚动；不出现横向滚动条。
- 所有内容本地内置，不依赖网络。
